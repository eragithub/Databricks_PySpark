# Databricks & PySpark Data Engineering Portfolio

This repository contains my hands-on practice, pipeline code, and project notebooks built using **PySpark** and **Spark SQL** inside the **Databricks** ecosystem.

## 🛠️ Skills & Concepts Covered
* **Architecture:** Spark Cluster Mechanics (Driver, Workers, Executors), Lazy Evaluation, DAGs.
* **Core API:** Data transformations, filtering, aggregations, schemas, and complex data formats (CSV, Parquet).
* **Lakehouse Features:** Unity Catalog management (Catalogs, Schemas, Volumes), Delta Lake fundamentals.
